# Dinakar Sasank — GitHub Pages Portfolio

A responsive, dark, engineering-focused portfolio website built with plain HTML, CSS and JavaScript.

## Deploy to GitHub Pages

1. Create a repository named `devarasasank31.github.io` under the GitHub account `devarasasank31`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your portfolio will be available at:
   `https://devarasasank31.github.io/`

## Customize

- Replace project links when individual repositories are ready.
- Add a `resume.pdf` to the root and add a Resume button if desired.
- Update experience/metrics whenever your CV changes.
