# 🧠 HOW I SOLVE PROBLEMS

```java
public class Engineer {

    public Solution solve(Problem problem) {

        problem.understand();

        Architecture architecture =
                design(problem);

        Solution solution =
                build(architecture);

        solution.test();

        while (!solution.isReliable()) {
            solution.debug();
            solution.optimize();
        }

        solution.ship();

        return solution;
    }
}
```

```text
     ↓

     ↓

     ↓

```
