## Deploy on GitHub Pages

1. Create/use a repository for the portfolio.
2. Upload the contents of this folder to the repository root.
3. Commit and push to `main`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. The included workflow will deploy the site.
7. Your URL will be:
   `https://devarasasank31.github.io/<repository-name>/`

If this is your special `devarasasank31.github.io` repository, the URL will be:
`https://devarasasank31.github.io/`
