# Dinakar Sasank — GitHub Pages Portfolio

Modern, responsive portfolio for **Dinakar Sasank**, B.E. Information Science Engineering, **2026 graduate**.

## Deploy
1. Upload the contents of this folder to the portfolio repository.
2. Go to **Settings → Pages**.
3. Select **GitHub Actions** as the source.
4. Push to `main`.

The portfolio is deliberately self-contained: the main CSS and profile photo are embedded in `index.html`, avoiding GitHub Pages path problems on project sites such as `/sasankportfolio/`.
