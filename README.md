```text

     ↓

     ↓
Nearby Users Alerted
```

* ⚡ 1-second live updates

**Stack:** `Node.js` · `Socket.IO` · `Firebase` · `GPS` · `Real-Time Systems`

**Stack:** `WebRTC` · `Service Workers` · `IndexedDB` · `Mesh Networking`
